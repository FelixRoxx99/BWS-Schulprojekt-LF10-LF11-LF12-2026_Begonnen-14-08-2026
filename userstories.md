# User Stories

1. Als Benutzer möchte ich mich anmelden können, damit nur berechtigte Nutzer Zugriff haben.
   - AK: Login mit gültigen Daten möglich; ungültige Daten werden abgewiesen.

2. Als Benutzer möchte ich alle Geräte in einer Übersicht sehen, damit ich den Bestand überblicke.
   - AK: Tabelle zeigt Geräteliste; Spalten lesbar; double-click öffnet Detail/Edit.

3. Als Mitarbeiter möchte ich ein neues Gerät erfassen, damit es im Inventar geführt wird.
   - AK: Formular mit Pflichtfeldern; nach Speichern erscheint Gerät in Übersicht.

4. Als Mitarbeiter möchte ich den Status eines Geräts ändern (z. B. Ausleihen), damit die Verfügbarkeit korrekt ist.
   - AK: Statusänderung wird gespeichert und farbig in der Tabelle angezeigt.

5. Als Administrator möchte ich Benutzer verwalten können, damit Rollen und Zugriffe gesteuert werden.
   - AK: Admin-Page sichtbar für Admins; Admin kann Benutzer editieren (NiA: vollständige CRUD-Funktionen noch erweiterbar).
